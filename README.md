# Gradient Lab — 경사하강법 시뮬레이터

Streamlit 없이 HTML/CSS/JavaScript만으로 동작하는 정적 웹사이트입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 별도 설치, 빌드, Python 서버가 필요 없습니다.

## 배포 / QR 공유

1. GitHub 저장소에 `index.html`, `style.css`, `app.js`를 업로드합니다.
2. GitHub 저장소의 **Settings → Pages → Build and deployment → Deploy from a branch**에서 `main` 브랜치의 `/ (root)`를 선택합니다.
3. 배포 후 발급된 `https://사용자명.github.io/저장소명/` 주소를 QR 코드 생성 서비스에 넣습니다.
4. QR 코드를 스캔하면 누구나 사이트를 열 수 있습니다.

GitHub Pages는 공개 정적 사이트를 호스팅합니다. 개인 기록, 퀘스트, XP는 각 방문자의 브라우저 `localStorage`에 따로 저장되며 서버에 업로드되지 않습니다. 브라우저 데이터 삭제, 시크릿 모드 또는 기기 변경 시 이전 기록이 유지되지 않을 수 있습니다.

## 구현 내용

- 원본 Python v9의 계산 로직 및 결과 판정 (시작점 8, f(x)=x², 임계값 1e-5, 클리핑 1e5)
- 학습률 0.05~1.50 / 0.05 간격, 최대 이동 1~10회
- 고정 좌표축 위 축구공 애니메이션, 이동 경로, 결과 및 점수
- 성공/실패/느린 수렴(거북이) 3초 화면 효과, 터치로 닫기
- 6개 퀘스트, 5개 규칙 발견, 총 10,000 XP 보상 및 연구자 모드
- 보상 수령 후 마스터 팝업 + 팝업 위 전체 화면 불꽃놀이
- 개인 기록 표, 점수 변화 차트, CSV 다운로드
- 모바일 반응형, 닉네임 및 기록 로컬 저장

## 파일

- `index.html` — 화면 구성
- `style.css` — 전체 디자인 및 반응형 스타일
- `app.js` — 시뮬레이션, 애니메이션, 퀘스트, 저장, 차트

## 참고

서버 없이 실행되므로 이용자 간 경험치 공유, 로그인, 관리자 대시보드는 제공하지 않습니다. 원본 v9의 퀘스트 완료 알림 문구 중 일부 과거 보상 수치 표기는 실제 보상 테이블과 달랐으므로, 본 버전은 실제 보상(총 10,000 XP)을 기준으로 표시합니다.
